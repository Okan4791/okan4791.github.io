Problem

A clean-looking scan can still be incomplete.

AUR incidents leave different evidence in installed packages, ALPM timelines, build artifacts, persistence paths, and shell history. Missing a root or skipping an unreadable file must not be reported as a clean machine.

Incident lists also change. Online freshness cannot be allowed to replace a known, trusted baseline without integrity checks.

Decision

Model evidence, provenance, and scan coverage separately.

Bundled campaign lists support offline scans. Online scans atomically cache parsed updates while retaining the trusted local baseline. An integrity manifest protects the IOC registry and bundled lists.

Reports carry retrieval dates, source details, expected and actual hashes, and coverage counters. Incomplete coverage exits with a distinct status even when the engine finds no compromise indicator.

Result

Detection and recovery share one auditable record.

Package, timeline, artifact, IOC, audit, and hardening checks produce text or JSON reports. Guarded recovery commands offer dry runs, explicit application, backups, and post-action verification.

Native Rust tests cover command routing, exit policy, report schemas, compressed logs, list integrity, incomplete coverage, and recovery safeguards.
